# LedgerMind

LedgerMind is an AI-powered financial reconciliation and analysis application built with Python and Streamlit.

## Features

- Bank statement and ledger reconciliation
- Data quality and validation checks
- Anomaly detection
- Financial alerts
- Cash runway forecasting
- AI-powered financial question answering
- Financial briefing and summary generation
- Historical reconciliation tracking

## Technologies Used

- Python
- Streamlit
- Pandas
- Machine Learning
- Google Gemini API

## Project Structure

- `app.py` - Main Streamlit application
- `reconcile.py` - Reconciliation logic
- `data_cleaning.py` - Data validation and cleaning
- `anomaly_detector.py` - Anomaly detection
- `forecast.py` - Cash runway forecasting
- `alerts.py` - Financial alert evaluation
- `qa_agent.py` - AI question-answering system
- `controller.py` - Main control and briefing logic
